# Auto-Steuerung (C# Consolenprojekt)

## Funktionen
- zwei Autos werden erstellt
- Benutzer kann ein Auto auswählen
- Aktionen für die Geschwindigkeit: beschleunigen oder bremsen

## Struktur
- Klasse `Auto` mit Farbe, Marke, Baujahr, Höhstgeschwindigkeit
- Methoden: `beschleunigen()`, `bremsen()`
- Benutzerinteraktion über Konsole

## Starten
Einfach in Visual Studio öffnen und starten.
