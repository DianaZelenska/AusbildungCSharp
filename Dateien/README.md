# WinForms CSV Datei erstellen/lesen
Ein kleines Windows Forms Projekt in C#, bei dem Benutzerdaten gespeichert und angezeigt werden.

## Funktionen
- Eingabe von Nachname, Vorname, E-Mail, Geschlecht (radiobuttons)
- speichern in einer `Person.csv` Datei
- Lesen der Datei und Anzeigen aller Nachnamen aus der Datei in einer Liste
- Falls eine Datei `Nachname.png` existiert (z.B. `Mustermann.png`), wird das Bild angezeigt.

## Speicherung
Datei `Person.csv` wird im selben Ordner wie `.exe` gespeichert.

## Starten
Projekt in Visual Studio öffnen und starten.
