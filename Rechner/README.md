# WinForms Taschenrechner
Ein einfacher Taschenrechner in C#, der grundlegende Rechnenoperationen unterstützt und eine Liste der bischerigen Berechnungen anzeigt.

## Funktionen
- Grundoperationen (Addition, Substraktion, Multiplikation, Division)
- Restart
- Ergebnisse werden in einer ListBox als Verlauf angezeigt

## Starten
Projekt in Visual Studio öffnen und starten.
