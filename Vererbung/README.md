# Vererbung und Geometrie in C#
Dieses Konsolenprojekt zeigt die Nutzung von Vererbung zur Berechnung von Fläche, Umfang oder Volumen, Oberfläche verschiedener geometrischer Figuren.

# Klassen
- `Quader`
- `Quadrat`
- `Rechteck`
- `Wuerfel`

# Starten
Projekt einfach in Visual Studio öffnen und starten.
