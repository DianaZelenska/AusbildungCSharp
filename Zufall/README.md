# ZahlRaten Spiel (WinForms Projekt)
Ein einfaches Windows Forms Spiel in C#, bei dem man eine zufällige Zahl zwischen 1 und 20 erraten muss.

## Funktionen
- Zufallszahl zwischen 1 und 20 wird generiert
- Benutzer gibt eine Zahl ein
- Rückmeldung: Zahl ist zu groß/klein oder "Sie haben erraten. Anzahl der Versuche: "
- Button `Restart`

## Starten
Projekt in Visual Studio öffnen und starten.
